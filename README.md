# homebrew-tap

Personal Homebrew tap for [beamlynx-desktop](https://github.com/beamlynx/beamlynx-desktop).

```
brew install --cask beamlynx/tap/beamlynx
```

Currently arm64 (Apple Silicon) only, and unsigned/unnotarized -- if macOS
Gatekeeper blocks the first launch, right-click `beamlynx.app` in Finder and
choose Open. See [SIGNING.md](https://github.com/beamlynx/beamlynx-desktop/blob/main/SIGNING.md)
in the main repo for status on that.
